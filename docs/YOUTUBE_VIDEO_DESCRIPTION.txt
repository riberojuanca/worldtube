TITLE
WorldTube – an AGPL desktop video client with tabs and a persistent mini player

TEXT
I built WorldTube, an AGPL-licensed local-first desktop video client for Windows and Linux.

It includes:

- Persistent mini player
- Independent tabs
- Local profiles and accounts
- Saved videos and playlists
- Keyboard shortcuts
- Live video support
- Local export and import
- Automatic update checks

The longer-term direction is to add an optional self-hosted server so profiles and libraries can eventually be synchronized between desktop and mobile devices, while keeping local use available. That server and mobile client are future plans, not implemented features yet.

I’m sharing the project because the source code, releases and a short demo are now publicly available.

# Application Languages

English is the default interface language. Spanish can be selected in
Account > Application > Language without restarting the application or players.

The language and startup update-check preference are stored globally in
`settings.appPreferences` inside `worldtube-data.json`. They are included in the
existing full-data export/import. Importing a package reloads the preferences.

Translations live in `src/shared/locale.ts`. Existing Spanish phrases are stable
keys during the migration; new English phrases have Spanish equivalents. Use
`t(source, values)` for interface copy and placeholders, and `useLocale()` in
components to subscribe to language changes. Never translate user names, video
titles, descriptions, playlist names, URLs, IDs or protocol constants.

Renderer date formatting follows the selected language. Shaka control labels
use its own localization API. Generated main-process counts and export/import
dialog titles also follow the preference. Existing video metadata is not
refetched when changing language; text supplied by YouTube retains its source
language. Unknown third-party error messages remain unchanged.

The public README and new implementation documents are English. Historical
handoff entries and earlier technical documents still contain Spanish and are
retained as development history rather than silently rewritten.

No production builds, typechecks or automated UI tests were run for this change.
The development process was restarted to load the new desktop APIs.

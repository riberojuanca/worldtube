Linux installation

Ubuntu / Debian · DEB

  1. Choose Linux · DEB above to download the Ubuntu / Debian x64 installer.
  2. Open the downloaded file with your software installer, if available, and confirm installation.
  3. Open WorldTube from your applications menu.

Install with commands

Press Ctrl + Alt + T in Ubuntu to open a terminal. Click Copy commands below, paste with Ctrl + Shift + V, then press Enter. These commands download and install WorldTube with APT.

mkdir -p "$HOME/Downloads" &&
cd "$HOME/Downloads" &&
wget -O WorldTube.deb 'https://github.com/riberojuanca/worldtube/releases/download/v0.0.4/WorldTube-0.0.4-linux-amd64.deb' &&
sudo apt install ./WorldTube.deb

Installation asks for your password; typing it does not display characters. Confirm the installation when prompted.

For a later version, download and install the new DEB. We do not currently provide an APT repository.

Ubuntu package installation guide

Portable · AppImage

Download AppImage · Linux x64
  1. Download the AppImage to a folder you want to keep.
  2. Right-click the file, open Properties → Permissions, and allow executing it as a program. Labels may differ between file managers.
  3. Open the file to run WorldTube. This portable format does not install a DEB package.

If it fails with a FUSE error, use the DEB on Ubuntu or follow the AppImage FUSE guide. Do not run WorldTube as root or disable system security settings to launch it.

Current Linux downloads are x64 only, not ARM. Flatpak and Snap packages are not provided.
